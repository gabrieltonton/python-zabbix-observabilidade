
# Python para Zabbix, Grafana e Observabilidade

## Sobre o projeto
Este repositório documenta minha evolução no
aprendizado de Python, com foco em automação de
infraestrutura, monitoramento e observabilidade.

## Tecnologias
- Python
- Zabbix API
- Grafana
- Git e GitHub
- APIs REST e JSON
- Automação de infraestrutura

## Trilha de aprendizado
- [ ] Fundamentos de Python
- [ ] Integração com APIs
- [ ] Inventário automatizado no Zabbix
- [ ] Cadastro automatizado de hosts
- [ ] Monitoramento personalizado
- [ ] Integração de eventos com n8n
- [ ] Análise de disponibilidade e SLA
- [ ] Projeto final: Auditor Inteligente de Hosts Zabbix

## Objetivo
Desenvolver soluções práticas para automatizar
processos e aprimorar o monitoramento de TI.

## Status
